# Azmari Bet · አዝማሪ ቤት

Mobile-friendly web app that installs on Android, iOS and desktop (PWA).

**Live:** https://nahom1927.github.io/Azmari-Bet/

## Install
- **Android (Chrome):** open the link → menu ⋮ → *Install app* / *Add to Home screen*
- **iPhone/iPad (Safari):** open the link → Share → *Add to Home Screen*
- **Desktop (Chrome/Edge):** install icon in the address bar

Data is stored in your browser (localStorage) on each device.
